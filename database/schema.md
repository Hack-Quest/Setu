# 🗄️ Setu Database Schema (Firestore)

This document outlines the exact data structures expected by the database modules. 
**Note for Frontend/Backend Teams:** Always use these exact key names when passing data to the `database` functions!

---

## 1. Needs / Reports (`needs_reports` collection)
When someone submits the Google Form, this is how the data is saved in Firebase.

| Field | Type | Description |
| :--- | :--- | :--- |
| `reporter_name` | String | Name of the person reporting |
| `reporter_phone` | String | Contact number |
| `location_text` | String | Raw address entered in the form |
| `description` | String | What happened / What is needed |
| `lat` | Float | Latitude (Generated by Geocoding module) |
| `lng` | Float | Longitude (Generated by Geocoding module) |
| `severity` | String | `critical`, `high`, `medium`, `low` (Generated by AI) |
| `category` | String | e.g., `medical`, `rescue`, `food`, `shelter` (Generated by AI) |
| `status` | String | `open`, `assigned`, `resolved` (Auto-managed by DB) |
| `timestamp` | String | ISO 8601 UTC Time (Auto-generated) |

---

## 2. Volunteers (`volunteers` collection)
When a volunteer registers on the platform.

| Field | Type | Description |
| :--- | :--- | :--- |
| `name` | String | Volunteer's full name |
| `phone` | String | Contact number |
| `skills` | List[String] | Array of skills (e.g., `["medical", "rescue"]`) |
| `lat` | Float | Latitude of volunteer's home base |
| `lng` | Float | Longitude of volunteer's home base |
| `available` | Boolean | `true` if free, `false` if deployed (Auto-managed) |
| `registered_at`| String | ISO 8601 UTC Time (Auto-generated) |

---

## 3. Assignments (`assignments` collection)
The "Smart Matches" created when a volunteer is dispatched to a need.

| Field | Type | Description |
| :--- | :--- | :--- |
| `need_id` | String | Firestore Document ID of the Need |
| `volunteer_id`| String | Firestore Document ID of the Volunteer |
| `assigned_at` | String | ISO 8601 UTC Time (Auto-generated) |
| `resolved_at` | String | ISO 8601 UTC Time (Populated when mission complete) |
